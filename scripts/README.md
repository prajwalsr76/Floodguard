# scripts: all code, by step (run from the project root)

| Folder | Step |
|---|---|
| `processing/` | water-level quality control |
| `aoi/` | study area, rain zones, station coordinates, flood event list |
| `gee/` | Google Earth Engine scripts and the importer for their exports |
| `stage1/` | Stage 1 features, training, lead-time test, live (operational) models |
| `stage2/` | Stage 2 grid, training table, training, cut-off tuning, improvement study, case studies |
| `realtime/` | analysis run, 2026 checks, browser engine, dashboard page and app |
| `live/` | the live service (`floodguard_server.py`), its Stage 1 engine and the Telegram helper |
| `common/` | shared config loader |

Commands in order: `docs/HOW_TO_RUN.md`.
