# 00_project: project documents and study area

* `FloodGuard_Project_Context_Master_v5.docx` (and `.pdf`): the final project report, 24 Oct 2026, with every final number (same values as `docs/RESULTS.md`). `v4` and `v3` are earlier versions, kept for history.
* `aoi/aoi_floodplain.geojson`: mapped area (15 km around Naraj, Kishan Nagar, Tarpur, clipped to the basin).
* `aoi/rain_zones.geojson`: the four rainfall sub-catchments. `aoi/mahanadi_basin.geojson`: CWC basin. `aoi/stations.geojson`: gauge locations.
* `aoi/flood_events.csv`: 53 candidate events from the Naraj record. `aoi/flood_events_qc.csv`: accept/reject of each Sentinel-1 mask after visual checking.
* `aoi/gee_upload/`: the same shapes as shapefile zips, for the optional Earth Engine asset route.
